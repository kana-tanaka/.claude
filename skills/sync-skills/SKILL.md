# スキルの同期 (sync-skills)

別ディレクトリの `.claude/skills/` 配下のスキルを、別プロジェクトの `.claude/skills/` へ同期する。
実処理はこのスキルに同梱の `sync-skills.sh` が行う。

## 使うタイミング

- 「このプロジェクトのスキルを別プロジェクトにも入れて/コピーして/同期して」
- あるリポジトリで育てたスキルを、別の作業ディレクトリへ展開したいとき

## 手順

1. **候補ディレクトリを集める。** 質問前に、選択肢として見せる候補を用意する。
   - まず作業ディレクトリの親をたどり、`.claude/skills` を持つプロジェクトを探す。例:

     ```bash
     # 現在の作業ディレクトリの親配下から候補を列挙
     find "$(cd .. && pwd)" -maxdepth 3 -type d -name skills -path '*/.claude/*' 2>/dev/null
     ```

   - 各候補は「プロジェクトルート」（`.claude/skills` の2つ上）として扱う。
   - 現在の作業ディレクトリ自身も候補に含める。

2. **同期元(SOURCE)を1問だけ確認する。** AskUserQuestion を使い、この質問単独で尋ねる（他の質問と混ぜない）。
   - 手順1で集めた候補ディレクトリを options に並べる。該当が無ければ「パスを直接入力」を促す。
   - SOURCE はプロジェクトルートでも `.claude/skills` でも可。

3. **同期先(TARGET)を1問だけ確認する。** SOURCE が決まってから、別の AskUserQuestion で尋ねる。
   - 候補から SOURCE と同じものは除いて options に並べる。
   - 該当が無ければパス直接入力を促す。

4. **同期するスキルを1問だけ確認する。** 必ず選択式で選んでもらう（全スキル一括同期はしない）。
   - SOURCE 配下のスキル名を列挙し、AskUserQuestion の `multiSelect: true` で options として見せる:

     ```bash
     ls -1 <SOURCE>/.claude/skills 2>/dev/null || ls -1 <SOURCE>
     ```

   - 選ばれたスキル名のみを後続コマンドの `[スキル名...]` に渡す。選択は最低1つ必須。

5. **まず dry-run で見せる。** 何が同期/削除されるか確認してもらう:

   ```bash
   bash <このスキルのディレクトリ>/sync-skills.sh --dry-run <SOURCE> <TARGET> [スキル名...]
   ```

6. **同期先の扱いを確認してから実行する。**
   - 既定（追加/上書きのみ・同期先の他スキルは残す）:

     ```bash
     bash <このスキルのディレクトリ>/sync-skills.sh <SOURCE> <TARGET> [スキル名...]
     ```

   - 完全ミラー（同期元に無いスキルを同期先から**削除**）。破壊的なので必ず確認してから:

     ```bash
     bash <このスキルのディレクトリ>/sync-skills.sh --mirror <SOURCE> <TARGET>
     ```

7. 結果（同期したスキル一覧）を報告する。

## 注意

- 既定は安全側（削除しない）。`--mirror` は同期先のスキルを消すので、実行前に必ず dry-run を見せて確認を取る。
- 各スキルはディレクトリ単位で同期される（`<skills>/<name>/` 丸ごと）。
- このスキル自体（`.claude` 共有リポジトリ向け）の変更は `develop` ブランチにコミットする。
