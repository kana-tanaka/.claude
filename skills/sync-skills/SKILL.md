# スキルの同期 (sync-skills)

別ディレクトリの `.claude/skills/` 配下のスキルを、別プロジェクトの `.claude/skills/` へ同期する。
実処理はこのスキルに同梱の `sync-skills.sh` が行う。

## 使うタイミング

- 「このプロジェクトのスキルを別プロジェクトにも入れて/コピーして/同期して」
- あるリポジトリで育てたスキルを、別の作業ディレクトリへ展開したいとき

## 手順

1. **同期元(SOURCE)と同期先(TARGET)を確認する。** 不明なら AskUserQuestion で尋ねる。
   - SOURCE / TARGET はどちらも「プロジェクトルート」でも「`.claude/skills` ディレクトリ」でも指定可。
   - 一部だけ同期したい場合は対象スキル名も確認する（省略時は全スキル）。

2. **まず dry-run で見せる。** 何が同期/削除されるか確認してもらう:

   ```bash
   bash <このスキルのディレクトリ>/sync-skills.sh --dry-run <SOURCE> <TARGET> [スキル名...]
   ```

3. **同期先の扱いを確認してから実行する。**
   - 既定（追加/上書きのみ・同期先の他スキルは残す）:

     ```bash
     bash <このスキルのディレクトリ>/sync-skills.sh <SOURCE> <TARGET> [スキル名...]
     ```

   - 完全ミラー（同期元に無いスキルを同期先から**削除**）。破壊的なので必ず確認してから:

     ```bash
     bash <このスキルのディレクトリ>/sync-skills.sh --mirror <SOURCE> <TARGET>
     ```

4. 結果（同期したスキル一覧）を報告する。

## 注意

- 既定は安全側（削除しない）。`--mirror` は同期先のスキルを消すので、実行前に必ず dry-run を見せて確認を取る。
- 各スキルはディレクトリ単位で同期される（`<skills>/<name>/` 丸ごと）。
- このスキル自体（`.claude` 共有リポジトリ向け）の変更は `develop` ブランチにコミットする。
